# carotos.org

[CarotOS](https://github.com/MiracLight/CarotOS) projesinin web sitesi.
Astro ile hazirlanmistir, Turkce ve Ingilizce olarak yayimlanir.

## Gelistirme

    npm install
    npm run dev      # http://localhost:4321
    npm run build    # dist/ klasorune derler

Node.js 22.12 veya ustu gerekir.

## Bakim

Yeni surum ciktiginda, ekran goruntusu eklerken veya surum notu yazarken
izlenecek adimlar KURULUM.md dosyasindadir.

## Lisans

Site kodu MIT lisansi altindadir. CarotOS adi, logosu ve marka gorselleri
kapsam disindadir. Dagitimin kendisi GPL-3.0 ile yayimlanir.
